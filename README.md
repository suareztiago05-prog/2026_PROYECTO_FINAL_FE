Proyecto Final – Clon de WhatsApp Web


Este proyecto consiste en el desarrollo de un clon funcional de la interfaz de WhatsApp Web utilizando React.
El objetivo es simular el flujo principal de mensajería, incluyendo lista de chats, visualización de conversaciones y envío de mensajes.

Tecnologías utilizadas
    React
    Vite
    React Router DOM
    CSS
    Vercel (deploy)

Funcionalidades
    Lista de chats
    Selección de conversación
    Visualización de mensajes
    Envío de mensajes mediante formulario
    Navegación entre páginas con React Router
    Diseño responsive (320px–2000px)

Enrutamiento
    Se implementó React Router DOM con rutas dinámicas para cada chat:
    /chat/:id

Estados
    Se utilizaron estados de React para:
    Chat activo
    Lista de mensajes
    Input de mensaje

Desafíos
    Manejo del estado entre componentes
    Diseño responsive tipo WhatsApp Web
    Simulación de datos de chats
    Estructuración de componentes reutilizables
